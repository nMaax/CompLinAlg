Final projects for *Computational Linear Algebra for Large Scale Problems* course at Politecnico di Torino

Reports of Homeworks can be found in `report_HW1.pdf` (PCA for customer analysis), `report_HW2.pdf` (Spectral clustering with inverse power deflation) and `report_HW3.pdf` (SVD for NLP in Latent Semantic Analysis). 

All related code can be found in respective folders `HW1`, `HW2`, `HW3`.
